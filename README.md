# probabilitysyndicate

One-page site for Probability Syndicate. Plain HTML + CSS, no build step.

- `index.html` — the page
- `styles.css` — styles

The audio section embeds the whole SoundCloud profile (soundcloud.com/probabilitysyndicate), so new uploads appear on the page automatically with no changes here.

Preview locally: open `index.html` in a browser, or run `python3 -m http.server` and visit http://localhost:8000.
